A sleek OTP verification UI with auto-focus, paste support, and success/error state animations. Pure HTML, CSS & JavaScript.

---

## ✨ Features

- 🔢 6-digit OTP input with auto-advance
- 📋 Paste support — fills all fields at once
- ✅ Success & ❌ Error state animations
- 🔄 Resend OTP with countdown timer
- ⚡ Zero dependencies
